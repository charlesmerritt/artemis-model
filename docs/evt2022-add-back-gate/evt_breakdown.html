Which EVT classes the add-back lands sit in

Every pixel in the five-county add-back, cross-tabbed against LANDFIRE 2022 EVT. The run already blocks cropland (evt2022_agriculture_v1) but lets pasture/hay and every Developed class through. Acres are 30 m pixels at 0.2224 ac.

By class group

Holes are TreeMap 2022 nodata on land. Proposed is any method before the crop gate. Coverage is added ÷ hole acres. Hansen-only is add-back no other method supports.

Filter scenarios

Each filter is applied to the gated proposals, then the 5 ac MMU (8-connected) is re-run. The re-run reproduces the shipped add-back to within 45 ac. Target classes are Southeastern Ruderal Grassland (9823) and Ruderal Shrubland (9323). Target lost to MMU counts target pixels lost because a filter cut their patch below 5 ac.

Adopted (V2): keep pasture/hay and the crop ban, and block Developed-Roads plus Developed Low, Medium and High Intensity (7296–7299). The full re-run with PR #94's county-improvement code added back 162,103 ac in 5,103 patches, within 34 ac of this estimate. Rasters: r2:artemis-r2/data/raster_improvement_data/processed/improved-rasters-evt2022-gate-v2/aoi_5county.
An allowlist of natural and ruderal EVT classes gives exactly the same result as S3, so it isn't listed separately.
Accuracy isn't re-estimated here. If the ~70% NAIP accuracy errors are mostly pasture and roadside pixels, S2/S3 remove most of them, but the label sample would need to be re-scored to confirm that.

How much of the target classes we never add back

Most of the missed ruderal grassland is bookend stratum 5, where no LANDFIRE bookend evidence exists. No method proposed it at all, so an EVT gate can't recover it. Only a new evidence source (the disturbance-dating work in #58) could.

Method

  • Run: r2:artemis-r2/data/raster_improvement_data/processed/improved-rasters-evt2022-gated/aoi_5county. Holes are treemap2022_provenance ∈ {2,3,4}, and add-back is {2,4} (849,926 px = 189,024 ac, matching summary.json).
  • EVT is LF2022_EVT_CONUS.tif clipped to the run grid. It is pixel-aligned with the run, so no resampling was needed.
  • Method bits: 1 bookends, 2 Obata, 4 Hansen. "≥2 methods" means bits 3, 5, 6 or 7.
  • The MMU was re-run AOI-wide rather than per county with padding, which changes the result by 0.02%. The donor step is assumed to stamp every surviving patch.
