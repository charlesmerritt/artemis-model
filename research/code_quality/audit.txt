Scope and standard

The final suite contains 30 Python test files with 337 test functions. This audit changes 47 existing functions, adds two mutation-workspace regression tests, and changes one viewer assertion. Some changes clarify existing checks rather than replace tautologies.

Every tracked test suite, pipeline doctest and quality-script doctest was inspected with its source behavior. Audit inventories are split between this file, spatial_audit.txt and management_audit.txt in this directory. Helpers/fixtures in tests/conftest.py and tests/arcpy_reference/leto_segmentation_fixture.py were also read. The transient unrelated FVSjl differential test was reviewed without editing; it is absent from the final branch.

A self-comparison or expected result drawn from the same production algorithm/constant cannot independently establish correctness. Replacements use worked literal outcomes. Valid preservation, determinism, rejection and independent-path parity properties remain. A legitimate property can be weaker than a complete specification without being a tautology.

Coverage and CRAP are distinct from assertion quality. Tests can execute code yet miss incorrect behavior; therefore in-process fault proofs and a fresh mutmut run supplement suite passes. See hardening.txt for measured scope, survivors and limitations.
